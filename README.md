# living-web-stack

It was my first contact with web development, and also with GitHub. Don't expect best practices or polished code: it's simply an initial exploration, and whatever comes next will be far better than this.

A quick pass through the most common technologies in web development, one folder per layer:

HTML → CSS → JS → HTTP/TLS → Python → SQL → REST APIs → Linux → Git → Docker → CI/CD + EXTRA (VSC).

This isn't a technical or professional project. It helped me see how the parts of a web app connect, and where I want to go deeper next. My current work is in my other repositories and on my site: https://dariuscc-dev.github.io
