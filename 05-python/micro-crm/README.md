# Micro-CRM CLI: Professional Outreach & Contact Manager

A Command-Line Interface (CLI) application developed in pure Python for efficient professional networking and outreach tracking. 

## Project Overview
This project was built to consolidate core Python programming fundamentals and showcase a production-ready approach to software design. Key technical concepts demonstrated include:
* **Object-Oriented Programming (OOP):** Structured data modeling using Python Classes.
* **Data Persistence:** JSON serialization and deserialization for local data storage (`File I/O`).
* **Robustness & Error Handling:** Implementation of `try/except` blocks to ensure application stability during user interaction.
* **Modularity:** Logical separation of concerns across multiple files (`main.py`, `models.py`, `database.py`).
* **Pythonic Paradigms:** Utilization of list comprehensions and standard library tools (`uuid`, `json`, `os`).

## Tech Stack
* **Language:** Python 3.x
* **Libraries:** Python Standard Library (No external dependencies)
* **Architecture:** Modular CLI script with JSON backend
